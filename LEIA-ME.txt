APP DE CHAMADA (instalável, funciona offline; layout para celular e PC)

ARQUIVOS: index.html, manifest.webmanifest, sw.js e os 3 ícones .png.
Mantenha todos juntos na mesma pasta/repositório, soltos na raiz (sem zip).

COMO ATUALIZAR O APP NO GITHUB
1. Descompacte o zip novo no computador.
2. No repositório, clique em Add file > Upload files e arraste os arquivos
   (pode arrastar todos; os de mesmo nome substituem os antigos).
3. Clique em Commit changes. Espere 1 a 2 minutos o Pages publicar.
4. Para o aparelho pegar a versão nova: abra o app com internet, feche
   completamente e abra de novo (às vezes é preciso abrir duas vezes).
   No PC, aperte Ctrl+Shift+R para recarregar sem cache.
Os dados salvos no aparelho NÃO são apagados ao atualizar.
O número da versão aparece no rodapé do app (ex.: "Versão 6"): use para conferir se a atualização chegou.
Regra: a cada atualização, o sw.js precisa ter o número da versão maior
que o anterior (chamada-v2 > chamada-v3 ...). Os zips que eu enviar já vêm assim.

DADOS: ficam no aparelho/navegador de cada pessoa. Para levar entre aparelhos,
use Pessoas > Backup > Exportar e depois Importar.
